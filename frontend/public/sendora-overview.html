Module 1 Architecture

Cold Email Outreach Flow (Step-by-Step)

This flow shows how user inputs are transformed into personalized emails with PDF attachments and delivered directly to recruiter inboxes:

1
Job Requirement & Recruiter Input Client State

User enters Recruiter Name, Recruiter Email, and pastes the Job Description into the Outreach form.

2
Gemini AI Email Framing POST /api/emails/generate

Backend pulls candidate profile constants (USER_NAME, USER_ROLE, USER_SKILLS, USER_RESUME_SUMMARY from .env) and prompts Gemini 2.0 Flash to craft a concise, compelling subject line and body.

3
Resume Attachment Resolution Resume Service / MongoDB

If "Attach Resume" is toggled on:
• Mode A (Existing): Fetches base64 PDF from MongoDB TailoredResume by ID and converts to Buffer.
• Mode B (New): Triggers buildTailoredResume() on the fly with the JD, compiles via XeLaTeX, saves to MongoDB, and attaches the binary buffer.

4
Nodemailer SMTP Dispatch POST /api/emails/send

Constructs full plain-text & styled HTML emails with automatically appended LinkedIn, GitHub, LeetCode, and Resume URLs. Dispatches via Gmail SMTP on port 465 SSL.

5
Audit Logging & Real-time Table Update MongoDB EmailLog

Saves recipient, subject, body, attached resume reference ID, timestamp, and success/failed status in MongoDB. Real-time updates the Outreach History table.

Module 2 Architecture

AI ATS Resume Builder & XeLaTeX Pipeline

How Sendora ingests candidate knowledge-base files, tailors LaTeX source code for ATS scoring, and compiles binary PDFs:

1
Knowledge Base Ingestion backend/knowledge-base/

The backend reads the master resume.tex, custom kyvernitis-resume.cls class file, and all markdown project READMEs located in backend/knowledge-base/readmes/.

2
AI Selection & LaTeX Modification POST /api/resumes/generate

Gemini analyzes the JD to select the most relevant projects and re-weights skill keywords. It generates a complete, compilable LaTeX document adhering strictly to the 1-page geometry.

3
XeLaTeX Local Compilation MiKTeX / TeXLive Subprocess

The backend writes temp files into backend/temp/ and invokes xelatex -interaction=nonstopmode. Compiles the ATS serif XCharter PDF in ~1.5 seconds.

4
Dual-format Persistence MongoDB TailoredResume

Stores the LaTeX text string + binary PDF encoded as base64 string in MongoDB. Exposes GET /api/resumes/:id/pdf to stream raw binary to the browser iframe.

Module 3 Architecture

AI Email Categorizer & Triage Engine

How inbound messages are classified and turned into actionable items and instant replies:

1
Inbound Email Submission POST /api/categorize

User pastes any incoming recruiter reply, assessment link, interview invite, or rejection email.

2
Strict Structured Classification Gemini 2.0 Flash (responseMimeType: application/json)

Classifies into one of 7 categories, assigns Priority P0-P5, extracts summary, action items, deadlines, sentiment score, and drafts a ready-to-send reply.

3
Kanban / List Triage Rendering React Categorizer View

Displays color-coded badges, urgency countdowns, action reminders, and status pills (Unread, Read, Replied, Archived).

4
1-Click Smart Reply or Custom Revision POST /api/categorize/reply

User clicks "Send Smart Reply" to immediately dispatch the AI response to the sender via Nodemailer, automatically marking the email status as Replied.

Client Architecture

frontend/

Built with React 19, Vite 8, and Lucide Icons with a dark glassmorphism design system:

  • • src/App.jsx: Main navigation tab orchestrator, Outreach state, Categorizer triage state, and global profile drawer.
  • • src/components/ResumeBuilder.jsx: Resume studio, JD input panel, live LaTeX editor, PDF iframe preview, and MongoDB resume library.

  • • vite.config.js: Local development server proxy routing /api/* directly to backend port 7000.
⚙️
Server Architecture

backend/

Built on Express 5, Mongoose 9, Gemini SDK, and Nodemailer:

  • • server.js: Express entry point with CORS, JSON body parser (15MB limit for PDFs), and route mounting.
  • • services/aiService.js: Google Gemini 2.0 Flash integration with JSON structured output schemas and fallbacks.
  • • services/resumeService.js: Knowledge-base loader, LaTeX modifier, and child process XeLaTeX compiler with temp file cleanup.
  • • services/emailService.js: Nodemailer transporter, HTML email formatter, social links signature builder, and PDF attachment handler.
  • • controllers/*: Request validation, error isolation, and DB operations for emails, resumes, and categorization.

REST API Endpoint Reference

Method Endpoint Request Body / Params Description
POST /api/emails/generate { jobRequirement, recruiterName } Prompts Gemini 2.0 Flash to return targeted subject & body JSON.
POST /api/emails/send { recruiterEmail, subject, body, attachResume, resumeMode, ... } Dispatches email via Nodemailer SMTP with optional PDF resume attachment.
GET /api/emails — Retrieves last 50 sent email logs from MongoDB.
POST /api/resumes/generate { jobDescription } Tailors LaTeX code and compiles PDF; saves record in MongoDB.
GET /api/resumes — Fetches saved resumes (excluding heavy base64 strings for speed).
GET /api/resumes/:id/pdf :id Streams compiled binary PDF directly with Content-Type: application/pdf.
DELETE /api/resumes/:id :id Deletes saved resume record from MongoDB.
POST /api/categorize { rawContent, subject, senderName, senderEmail } Classifies email, assigns priority, extracts deadlines, and drafts smart reply.
GET /api/categorize ?category=...&priority=...&status=... Lists categorized emails with search & filter support.
POST /api/categorize/reply { emailId, recipientEmail, subject, body } Sends AI-suggested smart reply via Nodemailer and marks status as Replied.
GET /api/health — Health check endpoint returning server status and timestamp.

Environment Configuration & Setup

Sendora uses a single authoritative backend/.env configuration file. Use the single-command workflow to initialize all dependencies: 

# 1. Clone repository
git clone https://github.com/RahulPrasad-78/Sendora.git
cd Sendora

# 2. Copy the authoritative environment template
cp backend/.env.example backend/.env

# 3. Install root, backend, and frontend packages simultaneously
npm run install:all

# 4. Start concurrent development servers
npm run dev

Authoritative Environment Variables Reference (backend/.env)

Variable Name Required Description & Purpose
PORT No Express server port (default 7000).
MONGO_URI No* MongoDB connection string (app has in-memory fallbacks if absent).
GEMINI_API_KEY No* Google AI Studio Key for Gemini 2.0 Flash (smart template fallback available).
USER_NAME Yes Your full name injected into AI prompts & email regards footers.
USER_ROLE Yes Your target role (e.g., "Full Stack Developer").
USER_SKILLS Yes Comma-separated skills list used by AI to highlight matches.
USER_RESUME_SUMMARY Yes Short bio injected into AI framing prompts.
USER_LINKEDIN, USER_GITHUB, USER_LEETCODE Yes Profile links automatically formatted into regards blocks.
SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS Yes Gmail SMTP credentials (requires 16-character App Password).
SMTP_FROM Yes From address for outgoing emails (typically same as SMTP_USER).
